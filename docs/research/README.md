# Research

The research log lives in the dataset, in [`data/research/`](../../data/research/), so it is validated and shown in the app (`/archive/research`). Facts move into `data/` only once verified (`canon-and-sources.md` §4).

| File                                                             | What it holds                                              |
| ---------------------------------------------------------------- | ---------------------------------------------------------- |
| [`sources.yaml`](../../data/research/sources.yaml)               | Every source used, what for, and whether it is evidence    |
| [`open-questions.yaml`](../../data/research/open-questions.yaml) | Unverified facts, gaps, and facts awaiting a footage check |
